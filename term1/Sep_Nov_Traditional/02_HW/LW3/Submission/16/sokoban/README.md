## Sokoban - Terminal Game

Това е конзолна версия на класическата логическа игра **Sokoban**, написана на **Java**.

Проектът включва собствен генератор на дъски, парсер, механизъм за откриване на deadlock-и и система за запис/зареждане на нива и статично генерирани такива.

---
## 📁 Структура

```

Makefile

levels/ # предварително генерирани нива

lib/

└── jline-terminal-3.30.6.jar # терминална библиотека за по-добър контрол на входа/изхода

src/

├── Main.java # входна точка на програмата

├── Game.java # основна логика на играта

├── Board.java / Tile.java # модел на дъската и клетките

├── BoardGenerator.java # генератор на случайни нива

├── BoardParser.java / BoardSaver.java # парсване и запис на нива във файлове

├── DeadlockDetector.java # откриване на безизходни ситуации

└── Position.java / StateDelta.java# помощни структури

```

---
## ⚙️ Компилация и стартиране

Има **два начина** да се пусне програмата:
### Чрез `make run`
```bash

make compile # компилира всички .java файлове

make run ARGS="-p 10 10 5"

```
Тук ARGS са аргументите, които се подават директно на програмата.
### Чрез .jar файл
```bash

make jar # създава самостоятелен fat JAR с всички зависимости

java -jar myprogram.jar -po level1.txt

```
Така приложението може да се стартира на всяка машина с Java, без нужда от Makefile или отделна компилация.
